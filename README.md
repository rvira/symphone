# Tutti

A playable hybrid orchestra: acoustic instrument sections meet electronic textures.

## Repository layout

```text
app/          Browser entry point and global styles
components/   Interactive orchestra interface
lib/          Score generation, instrument definitions and audio engine
public/       Static assets
tests/        Musical and transport invariants
```

This initial commit contains only the project scaffold. Feature implementation follows separately.

KHAOS is an interaction reference. Tutti is a separate implementation with its own orchestral composition and interface.
