# Crescendo design

The button queues to the next downbeat, then performs four bars in the current meter: gather, lift, surge, a half-beat breath and resolution. The score clock never restarts. These timings are Symphone design choices, not a prescribed formula from the sources below.

The swell changes musical density and note dynamics rather than sweeping a global high-pass filter. Bass stays present. String figures begin gently, harp motion joins, and a tuned percussion roll enters in the second half. The destination chord is taken from the current progression. Folk, classical and quiet scenes use softer accents than cinematic scenes.

Only instruments already in the score participate; mute, solo and levels still apply. Auto-evolve waits during the swell; queued melodies still enter at their normal cycle boundary. All embellishments are temporary—stored notes and user layers are not replaced. This uses existing sample/synth voices, not dedicated recorded tremolo or timpani-roll articulations.

## References

- [Berklee / Ben Newhouse: orchestration strategies](https://online.berklee.edu/takenote/orchestration-how-to-write-for-an-orchestra/) — instrument color, dynamics, harmony and rhythm should work together; woodwind rests allow breathing.
- [Sound On Sound: Arranging Pop](https://www.soundonsound.com/techniques/arranging-pop) — staged instrumentation and melodic direction create tension and release.
- [Vienna Symphonic Library: Timpani](https://preview.vsl.co.at/academy/percussion/timpani) and [Studio Percussion](https://preview.vsl.co.at/instruments/synchronized/percussion) — rolls and dynamic-roll articulations inform the restrained, pitched roll approximation.
